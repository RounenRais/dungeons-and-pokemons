# Credits

## Pokémon data and sprites

Species data, moves, evolution chains, sprites and cries come from
[PokeAPI](https://pokeapi.co) and the [PokeAPI sprite
collection](https://github.com/PokeAPI/sprites). Pokémon and Pokémon character
names are trademarks of Nintendo / Creatures Inc. / GAME FREAK inc. This is a
non-commercial fan project and is not affiliated with them.

## Icons

Every icon in the interface comes from [game-icons.net](https://game-icons.net),
licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) —
route map nodes, relics, map events, chest rewards and the odd flourish. They
are embedded in `components/icons/GameIcons.tsx`, which is generated by
`scripts/build-icons.py`; edit the `ICONS` table in that script and re-run it
to change the set.

Artists used: **Lorc**, **Delapouite**, **Carl Olsen**, **Caro Asercion**,
**Cathelineau**, and the game-icons **badges** set.

Item sprites in the shop and bag (Poké Balls, potions, stones) are the real
PokeAPI item sprites, not icons.

## Fonts

All served self-hosted through `next/font`, all under the SIL Open Font License:
Marcellus, Source Sans 3, Caveat and Press Start 2P.

## Battle UI sprites

The FRLG battle backgrounds, status panels and move effects in
`public/sprites/pokemon_frlg_sprite_pack/` were supplied with the project.

## Parchment texture

Generated procedurally by `scripts/build-parchment.py` — no third-party asset.
